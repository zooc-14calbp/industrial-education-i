# 工業の専門分野と59科目の参照箇所

確認日2026年11月4日。平成30年告示の工業編解説の掲載版を参照。印刷頁は本文下部の頁番号、PDF頁はファイルの先頭からの頁数。本文部分ではPDF頁が印刷頁より10頁多い。以下は各科目の節の開始頁である。

## 分野の全体像

50科目を12群にまとめた講義用の分類。工業編の科目表と各群の代表的な目標を参照し、土木・建築は内容の取扱いまで読む。[補足解説の設計](field-study-plan.md)を参照。

| 分野 | 科目 | 印刷頁 | 説明の焦点 |
|---|---|---|---|
| 機械と自動車と船舶 | 機械工作、機械設計、原動機、電子機械、生産技術、自動車工学、自動車整備、船舶工学 | 69～117 | 材料を加工する方法、機械の設計、動力、制御、生産、自動車や船舶を学ぶ。 動く仕組みだけでなく、加工・設計・安全・環境を結び付けて紹介する。 |
| 電気と電子 | 電気回路、電気機器、電力技術、電子技術、電子回路、電子計測制御、通信技術 | 118～160 | 回路、電気機器、電力、電子技術、計測制御、通信を学ぶ。 回路図、測定結果、装置の動作を対応させる授業例を示す。 |
| 情報技術 | プログラミング技術、ハードウェア技術、ソフトウェア技術、コンピュータシステム技術 | 161～181 | プログラム、ハードウェア、ソフトウェア、システムの構築や運用を学ぶ。 アプリの操作だけでなく、処理の仕組みと問題解決を扱う。 |
| 建築 | 建築構造、建築計画、建築構造設計、建築施工、建築法規 | 182～212 | 構造、空間の計画、構造設計、施工、法規を学ぶ。 見た目に加え、使いやすさ、材料、耐震、安全、法的条件を説明する。 |
| 建築設備 | 設備計画、空気調和設備、衛生・防災設備 | 213～232 | 設備の計画、空気調和、衛生や防災に関わる設備を学ぶ。 建物の骨組みと生活環境を支える設備の役割を分ける。 |
| 土木 | 測量、土木基盤力学、土木構造設計、土木施工、社会基盤工学 | 233～261 | 測量、土と水の力学、構造設計、施工、社会基盤の整備を学ぶ。 測る・記録する・図面にする・整備を考える学びのつながりを示す。 |
| 化学 | 工業化学、化学工学、地球環境化学 | 262～281 | 物質の性質と反応、製造の工程や装置、環境保全を学ぶ。 実験室の反応と、工業生産の流れ・装置を扱う学習を区別する。 |
| 材料 | 材料製造技術、材料工学、材料加工 | 282～301 | 材料の製造、性質と利用、加工を学ぶ。 製品の用途に応じて材料や加工方法を選ぶ説明例を使う。 |
| セラミック | セラミック化学、セラミック技術、セラミック工業 | 302～321 | セラミックの化学的な性質、製造技術、工業的な利用を学ぶ。 身近な製品から、原料・構造・性質・製造の関係へつなぐ。 |
| 繊維と染色 | 繊維製品、繊維・染色技術、染織デザイン | 322～336 | 繊維製品、繊維や染色の技術、染織のデザインを学ぶ。 外観だけでなく、材料の性質、製造、用途との関係を示す。 |
| インテリア | インテリア計画、インテリア装備、インテリアエレメント生産 | 337～357 | 住空間の計画、室内の装備、家具等のエレメント生産を学ぶ。 使う人と空間、材料、製作が結び付く例を使う。 |
| デザイン | デザイン実践、デザイン材料、デザイン史 | 358～373 | デザインの実践、材料、歴史を学ぶ。 装飾の紹介だけでなく、機能や社会生活の課題を捉える学びを説明する。 |
