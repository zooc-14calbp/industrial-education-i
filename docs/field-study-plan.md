# 工業の専門分野を理解する補足解説案

2026年11月4日。普通科高校出身で工業高校の授業を知らない受講生に向け、各分野で何を学び、どのような授業を行い、社会とどうつながるかを紹介する。専門的な計算や製作を受講生に課さず、視聴中心で理解できる部分を設ける。現在公開している動画・スライドへの組込み前の案である。

## 分野の捉え方

土木科・建築科などは、ここでは本科の「学科・専門分野」として整理する。高校卒業後に学ぶ制度上の「専攻科」とは区別する。学科名やコース名は学校によって異なり、学習指導要領の科目と学科は一対一で対応しない。[文部科学省の専攻科に関する説明](https://www.mext.go.jp/a_menu/shotou/kaikaku/1370599.htm)

工業編の内容構成は59科目で、原則履修科目2、各分野に共通する指導項目で構成された科目7、各分野に関する科目50に整理されている。共通する7科目が全て原則履修という意味ではない。各学校の教育課程で、どの科目をどう組み合わせるかを確かめる。[工業編 第1章第4節 印刷16～17頁 PDF26～27頁](https://www.mext.go.jp/content/20251203-mxt_kyoiku01-100002620_23.pdf#page=26)

分野別に別冊の解説があるという構成ではなく、工業編の各科目の節を組み合わせて読む。本案では50科目を12群に整理した。これは授業案の分類であり、全国共通の学科分類ではない。[59科目の参照箇所](field-subjects.md)と[分野別の対応表](field-map.json)を併用する。

## 既存の回への配置

| 回 | 補足する内容 | 視聴部分の目安と扱い |
|---|---|---|
| 第2回 学科と専門分野 | 12群を社会の仕事・製品・空間から紹介する | 既存の学科紹介を5～7分程度の全体像へ組み替える。科目名の暗記は求めない。 |
| 第6回 目標と資質・能力 | 分野が違っても知識・技術と判断・説明を関連付ける | 建築材料の選択、測量記録などを既存の例と差し替える。 |
| 第7回 科目構成と教育課程 | 土木・建築を詳しく読み、他分野の科目群を対照する | 土木・建築は各4～6分程度を仮置き。実測後、既存の説明と重複する箇所を削る。 |
| 第8回 基礎・実習・課題研究 | 同じ題材を科目の目的で読み分ける | 測量、模型、制御装置などを既存の事例へ組み込む。 |
| 第11回 教材研究 | 三面図、測定、配管断面積の教材を見る | 教材例3件を各2～3分程度。解答を提出させず、教師の解説を聞く部分にできる。 |
| 第12回 安全 | 系列別KYT教材を比較する | 実機の作業手順を教える授業ではなく、危険を捉える教材の役割を紹介する。 |
| 第13回 学習評価 | 作業の完成と、理解・判断の証拠を区別する | 国立教育政策研究所の電気回路の事例を既存の評価解説へ関連付ける。 |

各回へ一律に時間を上乗せしない。解説を聞いて理解を広げる部分と、演習で考える部分を区別し、既存演習を含む授業全体で調整する。専門分野の補足解説には、新たな必答クイズ、外部サイト全体の読解、提出課題を設けない。クイズを置く場合も任意の自己確認とし、科目全体のレポート2本という評価を維持する。

## 各分野で共通して説明すること

1. 身近な製品・建物・社会基盤などから、分野が対象にするものを示す。
2. 代表的な科目を2～3科目示し、それぞれの役割の違いを説明する。
3. 指導要領の目標、内容、内容の取扱いを一例ずつ関連付ける。
4. 図、模型、測定記録などを用い、具体的な授業を想像できるようにする。
5. 安全・環境・利用者・技術者の責任を、専門知識と切り離さずに扱う。

教師側は本文と解説を深く読み込むが、学生向け画面には要点と具体例を絞る。細かな科目名・条文・計算式を一枚に詰め込まず、原文へのリンクと参照箇所を補助資料へ残す。

## 土木分野で深めるポイント

「測量」は位置・距離・角度・高さを調べて記録し、図面や工事につなぐ学習である。解説は地形測量・路線測量などの実習、製図・実習との関連、技術者の倫理を扱う。写真測量と測量技術の利活用は、生徒や地域の実態、学科の特色に応じて選択して扱える項目であり、全校の同一実施を意味しない。参照：工業編第37節、印刷233～239頁、特に234頁。

「土木基盤力学」は土と水の力学的な扱いを中心とする。「土木構造設計」は構造物の力学や設計、「土木施工」は工事の方法・管理、「社会基盤工学」は自然環境や防災も含めた社会基盤整備を扱う。旧名称「土木基礎力学」を見つけた場合は、現行の名称変更と内容の再編を確かめる。参照：第38～41節、印刷240～261頁。

講義独自の例として、学校付近の排水を考える場面を使える。高さを測る、雨水の流れを考える、図面で伝える、施工・維持管理を考える、という異なる学びの役割を説明する。実際の学校での実施事例とは区別する。地図・標高の導入には[国土地理院の教材](https://www.gsi.go.jp/CHIRIKYOUIKU/index.html)を参照する。

## 建築分野で深めるポイント

「建築構造」は構法・材料・耐震技術など、「建築計画」は空間の使い方、快適性、省エネルギー、バリアフリー等を扱う。「建築構造設計」は力学と構造の設計、「建築施工」は工法や管理、「建築法規」は法的条件を扱う。建築を外観のデザインや大工作業だけで説明しない。参照：工業編第29～33節、印刷182～212頁。

「建築構造」の内容の取扱いには、地域の実態、建物の見学、メディア教材、実習の活用と、倫理観・法的側面からの考察が含まれる。「建築計画」には省エネルギー、バリアフリーとユニバーサルデザインの視点がある。学生向けには、公共の休憩空間を考える架空例から、見た目、使いやすさ、構造、安全、維持管理の関係を解説する。参照：第29節印刷183頁、第30節印刷189頁以降。

建築設備は、設備計画・空気調和設備・衛生・防災設備として別に読む。建物の骨組みと、快適性・衛生・防災を支える設備の両方が必要である。参照：第34～36節、印刷213～232頁。
