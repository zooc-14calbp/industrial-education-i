# 短い要点解説・話題提供・クイズの組替案

2026年11月4日。現在の動画初稿に対する次の改訂案です。このページの小単元を全動画へ追加済みという意味ではありません。

各回の既存の解説・クイズ枠を使い、①本文・解説の重要点1～2点を約4分、②関連する教材や実践例の一箇所を約3分、③思い出して答え、理由を確かめるクイズを約3分、という小単元へ組み替えます。授業全体の時間と負担を見て配分し、10分を一律に上乗せしません。Ⅱでは、総則・中学校との接続・各専門教科・キャリア教育等から、その回の内容に合う箇所を選びます。

## クイズの作り方

1. 説明前に一問を示し、分からなければ予想でよいと案内します。
2. 解説後は資料をいったん閉じ、要点を一言で思い出す問題と、具体例へ当てはめる問題に取り組みます。
3. 正解と理由、根拠の箇所を短く示し、回答を自分で修正します。誤答を誘うひっかけや、細かな条番号の暗記に偏らせません。
4. 次回冒頭や後の回で、一問を別の具体例として再出題します。

毎回の提出や成績への加点は設けず、科目全体のレポート2本という評価を維持します。長い文章は求めません。本人や家族の経験を答える問題は使いません。

思い出す練習が後日の保持に役立つことは、文章教材を用いた研究で示されています。これは、この講義の特定のクイズ形式や効果を検証済みという意味ではありません。[Roediger・Karpicke（2006）](https://doi.org/10.1111/j.1467-9280.2006.01693.x)

以下は選定候補です。実際の短い解説へ取り込む際に原文と前後の文脈を読み、具体的な箇所を確定します。重要点と参照箇所の対応、クイズの説明の正確さを確認してから動画の該当部分を差し替えます。
