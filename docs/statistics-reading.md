# 進路や学習の統計を読む活動

2026年11月4日。Ⅰ第4回の中高・高大等の進路、第9回の学習状況の資料では、対象・年度・分母・調べた内容を確認してからグラフを読む。数値から学校や生徒の優劣を判断する活動にせず、「言えること」「言えないこと」「次の確認」を一文ずつ考える。

Ⅱでは、[産業と進路のグラフを読む演習案](https://github.com/zooc-14calbp/industrial-education-ii/blob/main/docs/statistics-reading.md)と[演習PDF](https://github.com/zooc-14calbp/industrial-education-ii/blob/main/docs/statistics-exercise.pdf)を用意した。Ⅰ第4回では進路のグラフを紹介し、Ⅱ第3・9回で生徒への説明に使い直すことができる。両科目で同じ問いを重複して全て課す必要はない。

Ⅰ第9回では、国語・数学等の学力、専門分野の知識、実技、協働などを区別する。全国学力・学習状況調査と工業基礎学力テストは対象・内容が違うため、平均点を直接比べて学校や生徒の能力全体を説明しない。集計値から個人の背景や原因も推定しない。

この活動は考える時間に含める。高度な計算やグラフ作成ソフトの技能を新たな提出条件にしない。既存のメモやクイズを組み替え、科目全体のレポート2本へ活用する。
