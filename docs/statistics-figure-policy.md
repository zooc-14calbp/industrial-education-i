# 統計図表を講義用に作り直す方針

2026年11月6日。Ⅰ・Ⅱ共通の制作方針です。文科省・e-Stat・OECDなどの元表を確認し、各回の見直しに合わせて、分母・年次・対象範囲が分かる講義用の図へ順次差し替えます。

原表の表番号、公開年、基準年、対象、単位、分母、欠測の扱いを記録します。比率を計算し直す場合は分子・分母を残します。図には数値と出典を記し、色だけに意味を担わせません。本文と学習ガイドに「図から読み取れること」と「図だけでは分からないこと」を添えます。写真は説明に必要な場合に、撮影時期と権利を確認して使います。

Ⅱ第11回のOECD実データ図、Ⅰ第4回の進学率・地域比較図、Ⅱ第8回の学科別進路図、Ⅱ第1回の産業構成図を作成し、全媒体へ反映しました。ここで教材評価と内容確認を行います。[Ⅱ側の詳しい作業表](https://github.com/zooc-14calbp/industrial-education-ii/blob/main/docs/statistics-figure-policy.md)を参照します。図の更新時は、本文・スライド・学習ガイド・動画の対応も確かめます。
