# 工業科教育論Ⅰ 全15回の構成点検と次の改訂

> 更新：全15回の動画初稿と段階的な演習を追加しました。現行の進め方と時間は[実測時間と演習の設計](video-duration-current.md)、[動画一覧](../video/README.md)を参照してください。以下の70＋20分等は初期設計・以前の点検を含みます。


2026年11月4日。第1回は第2稿、第2～15回は1周目の初稿です。全15回の構成と活動のつながりを点検し、今後の改訂を以下の順で進めます。各回の制度・数値・実践例の最終確認と収録後の時間調整は、内容の改訂に合わせて行います。

## 各回の役割と改訂項目

| 回 | この回の役割 | 次の改訂項目 |
|---|---|---|
| 1 | 工業高校の学びの見取り図 | 第2稿済。学科と課程、基本用語、実習の流れを図表で補充。レポート案内を統一。 |
| 2 | 工業の学科と専門分野 | 分野と製品・設備の関係を図示し、専門用語の入口を整える。 |
| 3 | 授業と学校生活の具体像 | 出身校での経験を尋ねる導入を、公開資料や架空事例を読む活動に置き換える。 |
| 4 | 歴史と進路の広がり | 進学率の分母と時点を再確認。導入は個人の進路経験に依存しない問いにする。 |
| 5 | 法的根拠と原文の読み方 | 法的根拠の要点を保ち、指定する読解箇所を絞る。法令の全文読解は求めない。 |
| 6 | 目標と育成する力 | 活動名を学習目標に書き換える例を中心にする。授業全体の設計は第11・15回へつなぐ。 |
| 7 | 教育課程の配置を読む | 第1回の概観から進み、年次・選択・学校設定科目・注記の読み取りを深める。 |
| 8 | 三科目の目標と内容を比べる | 工業技術基礎・実習・課題研究の役割を対比。実践報告の検討は第10回に置く。 |
| 9 | 学習状況を支援に結ぶ | 調査の対象と限界を明確にし、単位換算の架空事例を具体化。「少数」の誤記を「小数」に直す。 |
| 10 | 課題学習の設計と実践 | 公刊された情報科の実践と追跡調査を読み、工業科への応用条件を考える。植物画像の架空授業案と区別する。 |
| 11 | 目標に合う教材を選ぶ | 比較用の教材や短い手順書そのものを用意し、修正前後を検討できるようにする。 |
| 12 | 実験・実習の安全を設計する | 作業空間と監督・相談の位置関係を図示する。個別機械の操作技能の習得とは区別する。 |
| 13 | 学習の根拠を評価する | 架空答案でルーブリックを試し、AI案と担当者の判断の一致・不一致を検討する。 |
| 14 | 教員の仕事と免許の全体像 | 職業に関する学科に関わる免許を一覧化。取得可能大学は年度と課程の条件を確認して紹介する。 |
| 15 | 目標・内容・指導・評価を統合する | 既出の学習メモをレポートBに使える形に整理し、新しい調査を必須にしない。 |

## 分量と活動

各回は解説・指定資料読解70分、クイズ・メモ・小休止20分の設計です。動画は未収録です。特に第9～15回は共通する導入やまとめを整理し、各回固有の資料を読む問い、具体例、解説を補う必要があります。スライド枚数だけで70分の分量を確定しません。

提出レポートは第9回後のAと第15回後のBの2本を基本とします。各回の短い活動は手元のメモで取り組み、毎回の提出課題にはしません。受講者の出身校・学歴・困難の経験の申告を前提にせず、公開資料と架空事例で取り組めるようにします。
