# 工業科教育論Ⅰ 授業構成案

前期 90分×15回。正式な開講年度と評価配分は未確定です。

| 回 | タイトル | 到達目標 |
|---|---|---|
| 1 | 高校教育の中の工業高校 | 普通科高校と専門高校の違いを捉え、工業高校の位置づけを説明できる。 |
| 2 | 工業高校の学科と専門分野 | 主な専門分野について、学ぶ内容の特徴を説明できる。 |
| 3 | 工業高校の授業 実習 学校生活 | 時間割や授業事例から、普通教科と専門教科を学ぶ教育の特徴を読み取ることができる。 |
| 4 | 工業教育の歴史と社会的役割 生徒の進路 | 工業教育と産業・地域社会との関係を捉え、中高・高大の進学率を対象や分母に注意して読み、卒業後の進路の特徴を説明できる。 |
| 5 | 学習指導要領の構成と読み方 | 総則、工業科の目標、各科目の目標・内容、内容の取扱いの関係を整理できる。 |
| 6 | 工業科の目標と育成する資質と能力 | 工業科の目標を、具体的な授業・実習で育てる力と結びつけて説明できる。 |
| 7 | 工業科の科目構成と教育課程 | 教育課程表と学習指導要領を照合し、科目配置や学習の順序の特徴を読み取ることができる。 |
| 8 | 工業技術基礎 実習 課題研究の検討 | 各科目の目標と内容を比較し、実践的な学習の役割を説明できる。 |
| 9 | 専門科目の内容と指導上の配慮 | 指定された専門科目の記述から、目標・内容に対応する指導上の配慮を挙げることができる。 |
| 10 | 高校における課題学習の設計と実践 | 実践事例から、課題設定、探究・解決の過程、生徒への支援、成果の振り返りを読み取ることができる。 |
| 11 | 工業科の授業づくりと教材研究 | 学習目標、学習活動、教材の関係を捉え、教材の工夫を説明できる。 |
| 12 | 実験 実習の指導と安全 | 実習事例から危険やつまずきを読み取り、必要な説明・環境整備・支援を挙げることができる。 |
| 13 | 工業科における学習評価 | 知識、作業過程、作品、報告書などについて、学習目標に対応する評価方法を考えることができる。 |
| 14 | 工業科教員の仕事と教科経営 | 授業準備、設備・材料の管理、教員間の連携など、工業科教育を支える仕事を説明できる。 |
| 15 | 工業科教育の目標 内容 指導 評価 | 一つの授業事例について、目標・内容・指導方法・評価のつながりを整理できる。 |
