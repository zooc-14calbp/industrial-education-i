# 工業科教育論Ⅰ 授業構成案

前期 90分×15回。正式な開講年度と評価配分は未確定です。

| 回 | タイトル | 到達目標 |
|---|---|---|
| 1 | 高校教育の中の工業高校 | 普通科高校と専門高校の違いを捉え、工業高校の位置づけを説明できる。 |
| 2 | 工業高校の学科と専門分野 | 主な専門分野について、学ぶ内容の特徴を説明できる。 |
| 3 | 工業高校の授業 実習 学校生活 | 時間割や授業事例から、普通教科と専門教科を学ぶ教育の特徴を読み取ることができる。 |
| 4 | 工業教育の歴史と社会的役割 生徒の進路 | 工業教育と産業・地域社会との関係を捉え、中高・高大の進学率を対象や分母に注意して読み、卒業後の進路の特徴を説明できる。 |
| 5 | 学習指導要領の法的根拠と読み方 | 教育基本法と教育課程の法的根拠、基準と創意工夫の関係を理解し、総則・工業科の目標・内容・取扱いを原文から読み取れる。 |
| 6 | 工業科の目標と育成する資質と能力 | 工業科の目標を、具体的な授業・実習で育てる力と結びつけて説明できる。 |
| 7 | 工業科の科目構成と教育課程 | 教育課程表と学習指導要領を照合し、科目配置や学習の順序の特徴を読み取ることができる。 |
| 8 | 工業技術基礎 実習 課題研究の検討 | 各科目の目標と内容を比較し、実践的な学習の役割を説明できる。 |
| 9 | 生徒の学習状況と専門科目の指導上の配慮 | 学力調査の対象・内容・限界を踏まえて生徒の学習状況を読み取り、専門科目の目標・内容に対応する支援を具体例で説明できる。 |
| 10 | 高校における課題学習の設計と実践 | 実践事例から、課題設定、探究・解決の過程、生徒への支援、成果の振り返りを読み取ることができる。 |
| 11 | 工業科の授業づくりと教材研究 | 学習目標、学習活動、教材の関係を捉え、教材の工夫を説明できる。 |
| 12 | 実験 実習の指導と安全 | 実習事例から危険やつまずきを読み取り、必要な説明・環境整備・支援を挙げることができる。 |
| 13 | 工業科における学習評価 | 知識、作業過程、作品、報告書などについて、学習目標に対応する評価方法を考えることができる。 |
| 14 | 工業科教員の仕事と教科経営 | 授業準備、設備・材料の管理、教員間の連携など、工業科教育を支える仕事を説明できる。 |
| 15 | 工業科教育の目標 内容 指導 評価 | 一つの授業事例について、目標・内容・指導方法・評価のつながりを整理できる。 |

## 生徒理解と学習支援の位置付け

第9回を中心に、生徒の既習事項、読む・計算する・図表を読み取る力、専門分野の理解、学習への自信や意欲を区別して扱います。測定・単位換算、作業手順の読解、図面やグラフの理解などの授業例から、つまずきの確認と説明・教材・活動の工夫を考えます。専門用語は普通科出身の受講生にも分かるよう説明します。第11回の教材研究、第12回の安全指導、第13回の学習評価でもこの視点を用います。

[令和7年度高等学校工業基礎学力テスト実施結果報告](https://zenkoukyo.or.jp/web/content/uploads/r07kisogaku_kekka.pdf)は、一般的な高校2年生までの専門分野の学習内容を扱う調査です（PDFの「はじめに」参照、報告日2026年2月6日）。国語・数学の一般的な基礎学力や入学時の学力を直接示す資料としては扱いません。対象・受験者数・分野・問題内容・得点分布を確認し、参加校の結果を工業高校生全体にそのまま一般化したり、分野別平均点を分野の優劣としたりしません。ペーパーテストの得点だけで実技や協働を含む能力全体を説明しません。

[工大サミット基調講演「全国の工業高等学校の現状と課題」](https://www.kait.jp/summit/program/pdf/program1.pdf)は学校・生徒・進路の背景と課題を把握する資料として参照します。収録された統計の年度と出典を確認し、現年度の状況と区別します。

70分の教材と20分の確認活動・小休止、全15回、科目全体で提出レポート2本程度の設計を維持します。第9回の確認活動は、指定された一つのつまずきに対する支援案を1～2文で考える程度とし、独立した提出レポートは追加しません。中高接続と中途退学・進路変更は、後期Ⅱ第10・13回で改めて扱います。
