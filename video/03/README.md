## 学び方

音声はNanami（Natural）、速度-5%、高さ変更なし。淡い灰緑の背景と濃い青灰の本文を継続し、字幕用の領域を確保しました。

動画の再生時間は **16:38（実測）**。指定資料の確認15～20分、中心となる演習35～45分、クイズと見直し5分、小休止5分を目安に、考える時間を含めて90分程度を目指します。計画試算は約76.6～91.6分です。学生による試用は未実施で、実測した授業時間ではありません。

動画中の資料確認やクイズは上記の目安に含み、重ねて加算しません。中心の演習は一つで、段階ごとに同じ表やメモを仕上げます。書き終わったら先へ進め、時間を埋める作業は求めません。毎回の提出はなく、科目全体のレポートは二本です。本人や家族の経験の開示、AIへの登録・操作、実物の機器操作は不要です。

事前の説明・作業・記録・振り返りの四つの欄に、事実と学びをつなぐ提案を分けて整理する。
