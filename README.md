# 工業科教育論Ⅰ

工業高校の具体的な学びを知り、学習指導要領を手がかりに目標・内容・指導・評価を理解するオンデマンド教材の制作リポジトリです。前期90分×15回を想定しています。大学の正式な公開講座や確定シラバスではなく、教材の初稿です。

[15回の構成と到達目標](docs/syllabus.md)

各回のcontent.jsonに本文、解説メモ、出典、活動時間の設計を保存しています。表・本文は編集できます。制作はAIを利用しており、配信前の担当者による内容確認と試用を前提とします。

## 授業と評価の設計

教材の解説・指定資料読解は約70分、クイズ・メモ・小休止は計20分を想定します。動画は未収録で所要時間は未検証です。科目全体で提出レポート2本程度とし、毎回の活動を独立した提出レポートにしません。課題別ルーブリックとAIによる評価案を担当者が確認する運用を検討しています。配点等は未確定です。

## 更新

学校の編制、教育課程、URL、制度等は年度を確認して更新します。特定校の例と一般的な授業案を区別します。第三者の写真や資料本体、未公表の研究原稿、答案は登録しません。動画の編集元・個人情報を含む運営記録は別管理とします。

後期の[工業科教育論Ⅱ](https://github.com/zooc-14calbp/industrial-education-ii)は別リポジトリです。[利用と出典](RIGHTS.md)を確認してください。
