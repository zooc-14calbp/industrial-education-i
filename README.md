## 授業と評価の設計

教材の解説・指定資料読解は約70分、クイズ・メモ・小休止は計20分を想定します。動画は未収録で所要時間は未検証です。科目全体で提出レポート2本程度とし、毎回の活動を独立した提出レポートにしません。[レポート課題と評価基準](docs/report-assessment-guide.docx)には、第9回後の資料読解・支援案（600～800字）と第15回後の小さな授業案（800～1000字）、観点別0～2点のルーブリック、採点例、AI案を担当者が全件確認する手順を提案しています。字数は目安で、既出資料と架空事例で取り組めます。締切・配点・再提出等は未確定です。

## 1周目初稿の範囲

2026年11月4日、第1～15回のスライド・学生用ガイド・担当者用手引きの初稿がそろいました。第9～15回は各24枚です。動画は未収録で、解説と指定資料読解の70分という分量は収録・試用後に調整します。

第10回には、専門教科「情報」の課題研究の授業実践と卒業後調査を、工業科への応用を考える比較例として加えています。植物画像の題材は、技術開発を基にした架空の授業案であり、確認された教育効果を示すものではありません。第14回の免許の紹介は教科と取得経路の見取り図で、取得可能大学数の確定比較は次の改訂で行います。

## 更新

学校の編制、教育課程、URL、制度等は年度を確認して更新します。特定校の例と一般的な授業案を区別します。第三者の写真や資料本体、未公表の研究原稿、答案は登録しません。動画の編集元・個人情報を含む運営記録は別管理とします。

後期の[工業科教育論Ⅱ](https://github.com/zooc-14calbp/industrial-education-ii)は別リポジトリです。[利用と出典](RIGHTS.md)を確認してください。
