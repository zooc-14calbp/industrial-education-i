## 学修の進め方

動画視聴・資料の確認・考える時間・小休止を含め、1回90分程度を目安に学修します。動画自体を90分にする必要はなく、「70分＋20分」も固定の配分ではありません。時間を埋めるための説明や課題は加えず、到達目標の理解と受講生の負担を基準に調整します。 [詳しい進め方](docs/study-guide.md)を確認してください。

## 授業と評価の設計

授業全体90分を目標に、解説の分量を固定せず、資料読解と段階的な演習を重視します。動画は全15回の再生時間を実測しました。読解・演習の所要時間は試用前の目安です。成績は科目全体で提出するレポート2本により評価し、毎回の活動を独立した提出レポートにしません。[レポート課題と評価基準](assessment/README.md)には、第9回後の資料読解・支援案（600～800字）と第15回後の小さな授業案（800～1000字）、観点別0～2点のルーブリックを検討用の案としてまとめています。字数は目安で、既出資料と架空事例で取り組めます。締切・配点・再提出等は未確定です。

2026年11月4日、第1～15回のスライド・学生用ガイド・担当者用手引きの初稿がそろいました。第9～15回は各24枚です。全15回の動画初稿と演習用教材を追加しました。正式配信前の内容確認と学生による試用は未実施です。
