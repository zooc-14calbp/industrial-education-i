# 工業科教育論Ⅰ

工業高校で何を学ぶかを知り、学習指導要領や授業の記録を読みながら、授業・実習・評価の組み立て方を考えます。

[受講方法を読む](docs/study-guide.md) ／ [教材一覧を開く](#各回の教材) ／ [提出課題と評価基準](assessment/README.md)

## 最初に：受講方法を読む

**第1回の教材を開く前に、[受講方法](docs/study-guide.md)を読んでください。** 動画、スライド、学習ガイドの使い方と、提出が必要な課題を確認できます。確認後、下の「各回の教材」から指定された回へ進みます。

## 教材の使い方

[受講方法](docs/study-guide.md)を確認し、指定された回を開いてください。動画を止めて、表や本文を読みながら問いを考えます。音声・字幕は各回の案内から開けます。学習ガイドはPDFです。

「動画」の数字は再生時間です。授業全体は、読解・考える時間・小休止も合わせて1回90分程度を目安にします。

## 提出課題

[レポートA・Bの課題文と評価基準](assessment/README.md)を確認してください。提出は科目全体で2本です。各回のメモや確認問題は提出不要です。正式な提出先・締切は、授業の案内に従ってください。
