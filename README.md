# 工業科教育論Ⅰ

工業高校で何を学ぶかを知り、学習指導要領や授業の記録を読みながら、授業・実習・評価の組み立て方を考えます。

## 学び方と提出課題

- [授業の学び方](docs/study-guide.md)で、動画・資料・考える時間の使い方を確認できます。
- [レポートの課題文と評価基準](assessment/README.md)に、科目全体で提出するレポート2本の案を掲載しています。各回の確認問題やメモは提出不要です。
- [Ⅰ・Ⅱ共通の基本方針](docs/teaching-policy.md)では、言葉の意味を身近な例で確かめ、資料を読んで理由を説明する学び方を示しています。

## 教材の版と制作資料

各回の一覧は再編後の番号です。授業で指定された資料を使ってください。動画時間は再生時間の実測値です。資料を読み、考える時間や小休止を含めた授業全体の所要時間は、学生による試用で確かめる段階です。

- [本編教材の公開状況](docs/main-media-status.md)で、両科目の本編がそろった回を確認できます。
- [旧番号の動画と教材](video/README.md)は、旧版の回番号で整理しています。
- [再編の経緯と教材設計](docs/reorganization-proposal-20261105.md)と[各回の教材点検](docs/lesson-quality-review.md)は、制作・引継ぎ用の資料です。
